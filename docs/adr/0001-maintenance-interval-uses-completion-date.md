# Maintenance Task の次回予定日は完了日基準で再計算する

Maintenance Task の次回予定日 (`next_due_date`) は、完了時に「完了日 + interval」で再計算する。予定日（カレンダー固定）基準ではない。また、期限超過しても先取りで未来の予定を生成しない — 完了して初めて次の予定が1つだけ立つ。

理由：個人利用のメンテナンスは「忘れがちで遅れる」のが前提。カレンダー固定だと遅延したタスクが翌週も期限切れ表示になりストレス。完了日基準なら、遅れた場合に次回も自然にずれていく。先取り予定を作らないのは、未消化の予定が積み上がる混乱を避けるため。

## 例

「フィルター清掃 / 2週間ごと」のタスクで、本来 1/1 予定が 1/10 まで遅れた場合：

- 採用案（完了日基準）: 完了 → next_due_date = 1/24（1/10 + 2週間）
- 不採用案（予定日基準）: 完了 → next_due_date = 1/15（1/1 + 2週間）
